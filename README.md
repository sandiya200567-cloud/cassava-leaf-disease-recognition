Cassava Leaf Disease Recognition

Project: Cassava Leaf Disease Classification using Transfer Learning with MobileNetV2

Description

This project uses deep learning and transfer learning with MobileNetV2 to classify cassava leaf images and help identify possible leaf diseases.

Notebook

The Jupyter Notebook (RA2311026050246_PS06.ipynb) contains the project code and implementation.

Tools Used

* Python
* Google Colab
* TensorFlow/Keras
* MobileNetV2
* Jupyter Notebook

How to Run

1. Open the notebook in Google Colab.
2. Run the code cells in order.
3. Provide the required dataset when prompted.
4. Review the model results and predictions.
